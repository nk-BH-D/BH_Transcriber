# BH_Transcribator

🎧 Telegram-бот для транскрибации голосовых сообщений, кружков и аудио файлов.

## 📜 Пользовательское соглашение

Аудиозаписи обрабатываются локально на сервере проекта с помощью библиотеки faster-whisper и модели Whisper, разработанной OpenAI. Мы уважаем конфиденциальность ваших данных, поэтому аудио обрабатывается на сервере проекта и НЕ отправляется во внешние сервисы распознавания, другим физическим и(или) юридическим лицам или в API OpenAI. Сервис транскрибации не хранит аудиозаписи и не использует их для других целей, кроме транскрибации.

Отправляя боту голосовое сообщение, вы соглашаетесь на его обработку для получения текстовой расшифровки. Для этого аудиозапись передаётся сервису распознавания речи, используемому проектом.

Аудиофайл временно сохраняется на время обработки. После её завершения сервис удаляет временный файл. При техническом сбое удаление может не выполниться сразу.

Бот может сохранять Telegram ID пользователя, статистику использования и текст обращений, отправленных через функцию «Отзыв». Эти данные используются для работы бота и обработки обращений.

Распознавание выполняется автоматически и может содержать ошибки. Результат не следует считать точной или официальной расшифровкой.

Не отправляйте материалы, которые вы не вправе передавать для обработки, а также конфиденциальную информацию, если не хотите передавать её используемому сервису распознавания.

Используя бота, вы подтверждаете, что прочитали это соглашение.

## ✨ Возможности

- 🎙️ Распознавание голосовых сообщений Telegram
- 📊 Просмотр личной статистики
- 👍👎 Оценка результата транскрибации
- 📨 Отправка комментария или обращения

## 🚀 Начало работы

1. Откройте бота в Telegram и отправьте `/start`.
2. Прочитайте документацию и пользовательское соглашение.
3. Нажмите **«✅ Принять»**.
4. Подпишитесь на канал проекта.
5. Нажмите **«Проверить подписку»**.

Если бот не подтверждает подписку, попробуйте ещё раз через несколько секунд.

## 🎙️ Транскрибация

1. Откройте меню и нажмите **«Транскрибация»**.
2. Отправьте боту голосовое сообщение Telegram.
3. Дождитесь окончания обработки и получите распознанный текст.
4. При желании оцените результат кнопками 👍 или 👎.
   > Вы можете оценить только последнюю транскрибацию.
   >
5. Чтобы оставить комментарий, нажмите **«Отзыв»** и отправьте текст.

Пример отправки: пересланное голосовое из любово вашего чата, канала и т.д.

> Сейчас бот обрабатывает голосовые сообщения Telegram. Обработка обычных аудиофайлов и видео сообщений может быть недоступна.

## 📨 Обращения и отзывы

Чтобы отправить обращение:

1. Нажмите **«Отзыв»** после получения транскрипции.
2. Отправьте сообщение с комментарием.

Пример:

   В транскрипции неверно распознано название организации.
   Пример из полученного текста: «ООО Рога и копалки» вместо «ООО Рога и копыта».

После отправки бот покажет ID обращения. Сохраните его, если хотите сослаться на обращение позднее.

> Старайтесь корректно описывать проблему в противном случает обращение будет помечено как невалидное и не будет обработано. Бот не обрабатывает обращения, содержащие оскорбления, угрозы, спам и другие нарушения правил.

## 📊 Статистика

Нажмите **«Моя статистика»**, чтобы посмотреть:

- свой Telegram ID;
- дату регистрации;
- количество транскрибаций;
- оценки 👍 и 👎;
- статусы своих обращений.

## ⚠️ Internal service error

При ошибке бот присылает сообщение вида `Internal service error<code>: повторите попытку позже`.

`code` показывает, что именно пошло не так при обработке запроса. Значения кодов:

- **0** — не удалось отправить приветственное сообщение при регистрации.
- **1** — передан неизвестный тип клавиатуры при отправке сообщения.
- **2** — не удалось создать запись пользователя в базе данных.
- **3** — не удалось получить из базы данных информацию о принятии соглашения.
- **4** — не удалось сохранить в базе данных принятие соглашения.
- **5** — ошибка Telegram API при проверке подписки на канал.
- **6** — не удалось сохранить оценку транскрибации в базе данных.
- **7** — не удалось сохранить обращение пользователя в базе данных.
- **8** — не удалось получить статистику пользователя из базы данных.
- **9** — не удалось получить список обращений пользователя из базы данных.
- **10** — ошибка обработки голосового сообщения или аудиофайла: скачивание, отправка в Whisper или получение результата.
- **11** — ошибка обработки кружка или видео: скачивание, извлечение аудио, отправка в Whisper или получение результата.
- **12** — внутренняя ошибка при поиске обращения по ID.
- **13** — не удалось изменить статус обращения в базе данных.
- **14** — ошибка Telegram API при проверке подписки пользователя перед выполнением действия.
